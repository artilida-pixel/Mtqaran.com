# MTQARAN — mtqaran.am

Трёхъязычный (hy / ru / en) сайт с двумя направлениями:

- **Академия MTQARAN** — `/[lang]/academy` — карточки преподавателей и лекций.
- **Фонд развития армянских деревень** («Մենք ենք մեր գյուղերը») — `/[lang]/fund` —
  интерактивная карта Армении, список областей → деревень, карточка каждой деревни
  с краудфандингом на воркаут-площадку (цель 4 000 000 драм) и произвольные
  дополнительные проекты.

## Запуск

Нужен `.env` с двумя переменными: `DATABASE_URL` (строка подключения к
PostgreSQL) и `ADMIN_PASSWORD` (пароль админки).

```bash
npm install
npx prisma migrate dev
npm run db:seed   # 10 марзов, 954 села официального реестра, 2 лекции с YouTube
npm run dev       # http://localhost:3010
```

Админ-панель — `/admin` (без языкового префикса). Там можно одобрять/отклонять
предложенные жителями проекты и присланные фотографии сёл, а также вручную
обновлять собранную сумму по каждому сбору.

## Стек

Next.js 16 (App Router, `proxy.ts` вместо middleware), React 19, Prisma 7 +
PostgreSQL (драйверный адаптер `@prisma/adapter-pg` поверх `pg`), Tailwind v4,
Leaflet / react-leaflet. Локализация — через `app/[lang]` + JSON-словари в
`src/lib/dictionaries`, без сторонних i18n-библиотек. Деплой — Vercel,
продакшн на https://www.mtqaran.am.

## Модель данных (`prisma/schema.prisma`)

- `Region` / `Village` — марз и деревня (координаты, статус воркаут-площадки).
- `Project` — краудфандинговый сбор (`type: workout_ground | other`,
  `status: pending | active | completed | rejected`). Публично видны только
  `active`/`completed`; новые заявки с сайта попадают в `pending` и ждут
  модерации.
- `VillagePhoto` — присланная посетителем фотография села с подписью, тоже
  проходит модерацию в админке.
- `Lecturer` / `Lecture` — преподаватели и лекции Академии.

## Текущее состояние и что дальше

Сайт задеплоен и работает, но контент ещё наполняется:

1. **Деревни**: 954 села — это действующий реестр сельских населённых пунктов
   Республики Армения по марзам (`src/data/official-villages-954.json`).
   Координаты и локализованные имена берутся из открытого датасета GeoNames
   (страна `AM`), отфильтрованного по географической принадлежности к одному из
   10 марзов — точка проверяется на попадание в полигон марза из
   `src/data/armenia-regions.geojson` (geoBoundaries). Это осознанно исключает
   всё, что не входит физически в эти 10 полигонов (в т.ч. Арцах/Карабах,
   которого там просто нет, и Ереван, у которого нет районных сёл), а сверка с
   реестром дополнительно убирает города и посёлки, которые GeoNames мешает с
   сёлами. Локализация имён (hy/ru/en) взята из альтернативных названий GeoNames
   с эвристикой транслитерации, отличающей актуальное название от
   устаревших/исторических вариантов, которые GeoNames хранит вперемешку; там
   где армянского или русского имени не нашлось, используется английская
   транслитерация как запасной вариант. Пересобрать датасет:
   `node scripts/extract-villages.mjs` (требует `tmp_data/AM.txt`, скачанный
   ранее из geonames.org — исходники в `.gitignore`, при необходимости скачать
   заново с `download.geonames.org/export/dump/AM.zip`), затем
   `node scripts/filter-to-official-villages.mjs`. Фотографии сёл заливаются
   пачкой через `node scripts/import-village-photos.mjs <папка>`. У каждого села —
   автоматическая карточка сбора на воркаут-площадку (цель 4 000 000 драм,
   изначально 0 собрано); описания и реальный статус стройки по большинству сёл
   ещё предстоит заполнить вручную/через админку.
2. **Академия**: лекции берутся из плейлиста MTQARAN Academy на YouTube —
   https://www.youtube.com/playlist?list=PLY7A0f5wC8fhag7Wu7Srnhty4Is7v2Zf7 —
   это единственный источник контента для раздела, обновлять его нужно
   вручную в `lectureSeeds` (`scripts/seed.ts`) при появлении новых видео в
   плейлисте: указать `slug`, `videoUrl`, заголовки/описания на трёх языках,
   `category`, `durationMin`. При сиде превью-картинка и embed-ссылка
   (`youtube-nocookie.com`) генерируются автоматически из `videoUrl`
   (`src/lib/youtube.ts`). У лекций пока нет привязки к конкретному
   преподавателю (в видео не указано персональное имя докладчика) — карточка
   показывает источник как «MTQARAN Academy»; модель `Lecturer` осталась в
   схеме и подключится, когда появятся именные профили. Реальный видео-плеер
   встроен на странице `/[lang]/academy/[lectureSlug]`.
3. **Оплата**: краудфандинговые карточки показывают только прогресс-бар
   (цель/собрано), без реальной интеграции платежей — по решению на старте.
   Когда появится платёжный провайдер (Idram, Telcell, банк), нужно
   добавить реальный приём оплаты вместо ручного обновления суммы админом.

### Идея на будущее для Академии

В разделе Академии уже заложена мысль-мостик между двумя направлениями сайта:
лучшие практические проекты выпускников курсов можно внедрять прямо в
деревнях из Фонда развития — так знания превращаются в реальную инфраструктуру.
Пока это только текст-анонс на странице `/academy`, можно развить в полноценную
фичу (привязка лекции/трека к конкретной деревне-практикуму).
